Tanya destinasi, itinerary, atau budget. Lampirkan foto tempat, dokumen rencana, atau rekaman suara — semuanya dibaca.

Dijawab oleh AI — harga, jadwal, dan syarat dokumen tetap perlu dicek di sumber resmi.

Uji Multimodal

Empat endpoint bawaan diuji satu per satu, terpisah dari percakapan.

POST /generate-text

Hasil akan muncul di sini.

Tentang Proyek

Chatbot asisten perjalanan berbasis Google Gemini, dibangun dengan Express dan JavaScript tanpa framework.

Cara kerjanya

Browser mengirim seluruh riwayat percakapan ke /api/chat. Server menyusunnya jadi format Gemini, menempelkan system instruction sesuai gaya bahasa yang dipilih, lalu mengalirkan jawabannya kembali potongan demi potongan lewat Server-Sent Events.

API key hanya ada di server, tidak pernah dikirim ke browser.

Endpoint

  • POST /api/chatPercakapan multi-turn
  • POST /api/chat/streamVersi streaming
  • POST /generate-textPrompt teks
  • POST /generate-from-imageAnalisis gambar
  • POST /generate-from-documentRingkas dokumen
  • POST /generate-from-audioTranskrip audio

Gaya bahasa

Tiga persona dengan system instruction dan preset parameter berbeda. Slider di panel kanan menimpa presetnya kalau ingin diatur sendiri.
